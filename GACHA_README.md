# Cookie Post V2.1 Gacha

Based on V2.0 complete. Open index.html in Safari.

Click gacha object from the desk, then press the pink lower-right button on the gacha scene. The accepted mint capsule image animates out of the dispenser, shakes, and opens into a recipe note. The recipe note uses a cropped bird-pattern area from the approved mint main-menu background. Click Draw Again or Try This Recipe. Try This Recipe sets dough and shape, and keeps an optional draggable recipe guide across the studio. Icing/toppings remain manual tasks. Rarity split is Common 60%, Special 30%, Rare 10%.

This version makes no changes to the existing mail, poem, collection or other studio scripts. The 30 recipes are present both in JSON and a JS fallback so local Safari file:// works.
