# Cookie Post V2.12 — LXGW WenKai GB

The postcard poem, message, and signature now use LXGW WenKai GB. The font is loaded before Canvas paints a greeting card, ensuring the Send preview and exported PNG match.

The user's font files were placed in the local development copy at `assets/fonts/`. The downloadable ZIP packages omit font binaries. To run the downloaded website, put your own original `LXGWWenKaiGB-Regular.ttf` and `LXGWWenKaiGB-Medium.ttf` in `assets/fonts/`.

All wrapping-paper options, postcard borders, cookie arrangement, poetry API, and email security settings are unchanged.
