# Cookie Post V2.0 — Poetry in Send + My Collection

Based on V1.9 Send Step (all original assets and production API settings unchanged).

## 1. Poetry in a Letter moved to Send
- The existing `.poetry-box` markup moved verbatim from Package to Send.
- Existing `poetry.js`, Worker endpoint and generated poem validation unchanged.
- Added automatic Send-page greeting-card preview refresh after editing/generating/removing poem.
- Package holds wrapping paper, From, To and message. The Cookie PNG and Download Greeting Card buttons also moved to Send, using the original export listeners.

## 2. My Collection works locally
- The existing clickable journal opens a new My Collection page.
- `Save to My Collection` in Send stores PNG plus source drafts as a named entry in browser IndexedDB.
- Collection entries display card images and provide Edit (resume Package), Download and Delete.
- Multiple cards can be saved independently. Deleting is confirmed.
- Only works on the same browser/device/profile. Clearing site data or private browsing may erase the collection. This does not upload anything to a server.
- On Edit, the selected saved draft is restored to this browser and the page reloads to reinitialize existing editors. Unsaved current edits are replaced.

## Safety and scope
- Worker private-test upload and Turnstile lock remain unchanged; no email is sent automatically.
- All existing artwork unchanged; only Send layout and new Collection screen styled to match existing interface.
- No new image generation.

## Validation
- All local JavaScript files passed `node --check`.
- Verified element IDs, Poetry placement and packaging references structurally.
- Browser runtime test was blocked by the execution environment at both file:// and localhost. Please test Safari interactions and local IndexedDB storage.
